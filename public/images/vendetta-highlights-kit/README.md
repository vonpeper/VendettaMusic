# Vendetta Highlights Visual Kit

Kit por capas para implementar la franja horizontal de confianza posterior al hero.

## Archivos

- `flightcase-texture.png`: maestro raster.
- `flightcase-texture.webp`: versión web compatible.
- `flightcase-texture.avif`: versión web preferida.
- `cable-signal-desktop.svg`: cable rojo y plugs para escritorio.
- `cable-signal-mobile.svg`: recorrido compacto para móvil.
- `flightcase-hardware.svg`: perfiles, remaches, esquineros y placa sin texto.
- `design-tokens.css`: colores y familias tipográficas.
- `PROMPT-ANTIGRAVITY.md`: instrucción completa de implementación.

## Tipografía

- Display: Barlow Condensed 600–900.
- Funcional: Inter 400–600.

Los textos deben mantenerse como HTML. Los SVG son decorativos y pueden reposicionarse sin pérdida de calidad.
